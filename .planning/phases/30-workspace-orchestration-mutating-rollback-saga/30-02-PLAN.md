## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repo path → conjure update subprocess | repo_abs validated by CR-02 traversal re-check before subprocess call |
| subprocess stdout/stderr → aggregate report | output captured to TMPERR, scanned with grep — no eval, no shell expansion of subprocess output |
| non-TTY → mutating op | --yes flag required; non-TTY without --yes → exit 2 before any mutation |
