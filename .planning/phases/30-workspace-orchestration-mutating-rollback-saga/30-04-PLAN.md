<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| snapshot_rollback input | snapshot_ref path captured from state file (written by ws_do_adopt); not user-provided at restore time; validate -d before calling |
| sha256_pre_ref hash file | Path from state file (absolute mktemp path); verify -f before reading; hash file outside repo tree so rollback cannot clobber it |
| state file at rollback → filesystem writes | manifest_dir is workspace-root-validated; rollback writes only to repo_abs paths validated by CR-02 re-check |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-30-04-01 | Tampering | rollback restoring into out-of-bounds path (traversal at restore time) | mitigate | CR-02 traversal re-check (pwd -P boundary guard) per repo BEFORE snapshot_rollback call; out-of-bounds → record failure + continue (independence), never restore |
| T-30-04-02 | Repudiation | failed rollback silently reported as success | mitigate | sha256 zero-diff verify loop per repo; mismatch > 0 → per-repo failure recorded + aggregate exit 2; no path from mismatch to exit 0 |
| T-30-04-03 | Tampering | state file corruption → repos stranded mid-mutation | mitigate | workspace_state_validate at rollback entry; absent → exit 2 "nothing to roll back"; malformed → exit 2; atomic writes in ws_do_adopt ensure state is valid or absent |
| T-30-04-04 | Denial of Service | rollback loop halted on single-repo failure, leaving others unreached | mitigate | Independence: per-repo `continue` (not `exit 2`) on failure; any_failed flag; aggregate exit 2 only after loop completes — every repo attempted |
| T-30-04-05 | Tampering | sha256_pre_ref hash file path is writable by other processes (race) | accept | Hash files in /tmp owned by the running user; same risk profile as mktemp files used throughout the codebase; no escalation path |
| T-30-04-SC | Tampering | npm/pip/cargo installs | accept | No package manager installs in this plan |
</threat_model>
