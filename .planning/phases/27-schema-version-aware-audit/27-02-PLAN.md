<objective>
Wave 2: Implement SCHM-03 (unknown/renamed hook event detection) and SCHM-04 (--schema per-key CC-version report) in scripts/check.sh, plus --schema flag wiring in cli/conjure.

Purpose: SCHM-03 reads hook event names from .claude/settings.json, compares them against the lib/cc-schema.json hook_events[] list, and flags renamed (SessionStop→SessionEnd) and unknown events as exit 2. SCHM-04 is info-only: when CONJURE_SCHEMA=1 (--schema flag), check.sh prints a per-key report of which CC version introduced each settings key found in the harness. The SCHEMA_FAIL counter is added AFTER the existing `exit "$drift"` block so schema failures (exit 2) override drift (exit 1) without disturbing the existing drift path.

Wave 2 is independent of Wave 1 (different files: check.sh and cli/conjure vs audit-setup.sh). Both waves execute after Wave 0.
</objective>
