   - Optional-typed: version must be string if present; agents must be array if present; keywords must be array if present; hooks must be object if present; mcpServers must be object if present
   - Return 1 if errors > 0, else return 0
   - Caller must: validate_plugin_json "$PLUGIN_JSON" || exit 2

5. detect_github_source(target):
   - Run `git -C "$target" remote get-url origin 2>/dev/null` || return 1

6. resolve_version(target):
   - Tier 1: if $target/.conjure-version exists, cat it and return 0
