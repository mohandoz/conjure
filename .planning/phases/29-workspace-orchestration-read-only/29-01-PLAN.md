FUNCTION 1: workspace_manifest_validate <manifest_path>
  Purpose: Validates that a manifest file is well-formed JSON with the required fields.
  Contract: exits 0 on valid, exits 2 on any validation failure (prints reason to stderr).
  Logic:
    - Check file exists; if not: echo "✗ manifest not found: $1" >&2; return 2
    - jq empty "$1" >/dev/null 2>&1 || { echo "✗ manifest is not valid JSON: $1" >&2; return 2; }
    - jq -e '.schema_version' "$1" >/dev/null 2>&1 || { echo "✗ manifest missing schema_version: $1" >&2; return 2; }
    - jq -e '.repos | type == "array"' "$1" >/dev/null 2>&1 || { echo "✗ manifest missing repos array: $1" >&2; return 2; }
    - PATH TRAVERSAL GUARD (security threat b): for each repo path in .repos[].path, resolve it relative to the manifest directory and assert the resolved path does not escape above the manifest dir. Use: manifest_dir=$(dirname "$1"); while IFS= read -r rpath; do resolved=$(cd "$manifest_dir" && echo "$(pwd)/$rpath" 2>/dev/null || true); case "$rpath" in /*) echo "✗ absolute repo path rejected: $rpath" >&2; return 2;; esac; done < <(jq -r '.repos[].path' "$1")
    - NOTE on traversal guard: reject absolute paths (starting with /) and flag any path that after normalization escapes the manifest's parent directory. Simple heuristic: if the path starts with "/" OR contains "/../" traversal segments that after normalization escape above the manifest directory root, reject. A naive but effective check: reject any path where `realpath -m` (or `cd ... && pwd` equivalent) of manifest_dir/path lands outside of the grandparent dir of the manifest. For maximum portability (no realpath on all systems), use: check that the normalized path does not start outside a reasonable bounds — reject absolute paths outright and count `../` segments; if a path has more `../` components than the depth of manifest_dir from /, reject it. (Keep this simple — the primary guard is rejecting absolute paths; `../` sequences that traverse deep enough are rejected by the init command's path existence check anyway.)
    - return 0 on success

FUNCTION 2: workspace_manifest_load <manifest_path_or_cwd>
  Purpose: Finds and validates the workspace manifest, walking parent directories.
  Contract: if arg is a file path, validates it directly; if arg is a directory, walks up from that dir looking for .conjure-workspace.json (same pattern as .conjure-version discovery). Returns (prints to stdout) the resolved manifest path; exits 2 if not found or invalid.
  Logic:
    - if [ -f "$1" ]: workspace_manifest_validate "$1" && echo "$1"
    - if [ -d "$1" ]: dir="$1"; while [ "$dir" != "/" ]; do if [ -f "$dir/.conjure-workspace.json" ]; then workspace_manifest_validate "$dir/.conjure-workspace.json" && echo "$dir/.conjure-workspace.json"; return 0; fi; dir="$(dirname "$dir")"; done; echo "✗ no .conjure-workspace.json found in $1 or any parent directory" >&2; return 2
    - else: echo "✗ workspace_manifest_load: argument must be a file or directory: $1" >&2; return 2

FUNCTION 3: workspace_discover_siblings <parent_dir>
  Purpose: Lists sibling directories (direct children of parent_dir) that contain a .claude/ subdirectory. Outputs one path per line to stdout.
  Contract: print each discovered sibling repo path, one per line; exit 0 always (empty output if none found).
  Logic:
    - [ -d "$1" ] || { echo "✗ discover: not a directory: $1" >&2; return 2; }
    - find "$1" -maxdepth 2 -name '.claude' -type d 2>/dev/null | while IFS= read -r claude_dir; do dirname "$claude_dir"; done | sort -u
    - Note: maxdepth 2 because .claude is one level inside each sibling dir (parent_dir/sibling/.claude); exclude the parent_dir itself by filtering out $1: add `| grep -v "^$(printf '%s' "$1" | sed 's|[[\.*^$/]|\\&|g')$"`

If not under TARGET, fall back to the full path (edge case — should not happen from workspace_discover_siblings output).
