ws_do_check <manifest_path> <manifest_dir> function:
  Purpose: reads repos from manifest, runs conjure check --porcelain per repo, emits table.
  Exit codes: 0 = all repos clean; 1 = any repo drifted or errored (partial-success, fail-tolerant); 2 = hard error (invalid manifest, etc.)
  NOTE: exit 1 here is the SC-MANDATED documented exception — it is the "partial success" aggregate semantic, NOT a hard failure. This mirrors how audit's WARN→exit-1 gate is the project's documented exception.

  Logic:
    OVERALL_RC=0
    printf '\n%-30s %-15s %s\n' "REPO" "STATUS" "EXIT"
    printf '%-30s %-15s %s\n' "----" "------" "----"

    Iterate repos in manifest order using jq:
    while IFS= read -r repo_json; do
      repo_name=$(printf '%s' "$repo_json" | jq -r '.name')
      repo_relpath=$(printf '%s' "$repo_json" | jq -r '.path')
      repo_abs="$MANIFEST_DIR/$repo_relpath"

      BAD-PATH GUARD: if [ ! -d "$repo_abs" ]; then
        printf '%-30s %-15s %s\n' "$repo_name" "SKIP" "bad-path"
        printf '  ⚠ skipping %s: path not found (%s)\n' "$repo_name" "$repo_abs" >&2
        OVERALL_RC=1  # partial success
        continue
      fi

      Per-repo check invocation — MUST pass --porcelain as a flag to cli/conjure, NOT via env var.
      cmd_check in cli/conjure initializes porcelain=0 from scratch, so CONJURE_PORCELAIN in the
      environment is silently overridden. The only working form is the flag argument:
        REPO_RC=0
        PORCELAIN_OUT=$(bash "$CONJURE_HOME/cli/conjure" check --porcelain "$repo_abs" 2>/dev/null) \
          || REPO_RC=$?

      Map exit code to status label:
        case "$REPO_RC" in
          0) REPO_STATUS="clean" ;;
          1) REPO_STATUS="drift"; OVERALL_RC=1 ;;
          2) REPO_STATUS="error"; OVERALL_RC=1 ;;  # NOTE: per-repo exit 2 maps to overall exit 1 (fail-tolerant)
          *) REPO_STATUS="error($REPO_RC)"; OVERALL_RC=1 ;;
        esac

      Emit table row:
        printf '%-30s %-15s %s\n' "$repo_name" "$REPO_STATUS" "$REPO_RC"

    done < <(jq -c '.repos[]' "$MANIFEST_PATH")

    printf '\n'
    if [ "$OVERALL_RC" -eq 0 ]; then
      echo "✓ All repos clean."
    else
      echo "⚠ One or more repos have drift or errors (exit 1 — partial success)."
    fi

    return "$OVERALL_RC"

    WARN_COUNT=0
    PASS_COUNT=0

        case "$REPO_STATUS" in
          pass)    PASS_COUNT=$((PASS_COUNT+1)); TABLE_STATUS="pass" ;;

    elif [ "$OVERALL_RC" -eq 1 ]; then echo "⚠ Warnings only (exit 1 — partial success)."
