FUNCTION: cmd_eval_emit_workflow <target_dir>
  1. Source lib/mutate.sh (DRY_RUN=0) — already sourced by eval.sh at top-level but confirm it is available.
  2. mutate_mkdir "$target_dir/.github/workflows" — create the directory (backup-before-mutate per mutate_mkdir convention).
  3. Build the workflow YAML into a tempfile using printf line-by-line. Do NOT use a heredoc with variable expansion — Pitfall 3 applies. Each line is written with `printf '%s\n' "<line>" >> "$_wf_tmp"`. Use the exact structure from RESEARCH Pattern 5:

     - name: Conjure Eval
     - on: pull_request with paths: ['.claude/**', 'CLAUDE.md']
     - jobs: eval, runs-on: ubuntu-latest
     - permissions: contents read, pull-requests write
     - steps:
       a. actions/checkout@v4
       b. actions/cache@v4 (path: ~/.cache/promptfoo; key: ${{ runner.os }}-promptfoo-v1-${{ hashFiles('.conjure/eval/promptfooconfig.yaml') }}; restore-keys: ${{ runner.os }}-promptfoo-v1-)
       c. promptfoo/promptfoo-action@v1 with:
          - github-token: ${{ secrets.GITHUB_TOKEN }}
          - config: '.conjure/eval/promptfooconfig.yaml'
          - promptfoo-version: '0.121.14'   (use PROMPTFOO_VERSION variable — same constant)
          - fail-on-threshold: 80            (INTEGER — NOT 0.8; 80 = 80% pass rate required; maps from CONTEXT.md's 0.8)
          - repeat: 3
          - repeat-min-pass: 2              (action input; provides the minPassCount:2 intent from ROADMAP SC; NOT a YAML assertion key)
          - cache-path: ~/.cache/promptfoo
       d. env: ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}

  4. Write tempfile to "$target_dir/.github/workflows/conjure-eval.yml" via mutate_write_file (byte-exact, preserves trailing newline).
  5. rm -f "$_wf_tmp"
  6. Print: "▸ conjure eval --emit-workflow: wrote .github/workflows/conjure-eval.yml"
  7. Print the testable verification note (per cross-cutting invariant — every emitted artifact ships with verification):
     "  Verify: add ANTHROPIC_API_KEY to GitHub repo secrets; open a PR touching .claude/ to trigger the eval gate"
