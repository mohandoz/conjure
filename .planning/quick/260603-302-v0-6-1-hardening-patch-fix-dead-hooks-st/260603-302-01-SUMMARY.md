## What Was Fixed

### FIX-01: stdin-JSON contract (all three hooks)

All three hooks previously read from `process.argv[2]` / env vars. Claude Code delivers
payloads via stdin JSON; argv is never populated in production. All three hooks now mirror
`skill-telemetry.mjs`'s pattern: 5-second setTimeout guard, stdin chunk collection, JSON.parse
in the `'end'` handler, argv/env fallback for manual CLI invocation.

### FIX-02: gitleaks exit-status branch in pre-commit-quality-gate.mjs

The original `e.status !== undefined` check blocked on ANY non-zero gitleaks exit (including
tool errors, config errors, signal kills). Fixed to: exit 1 = confirmed finding (BLOCK);
signal = warn stderr but exit 0; other non-zero = warn stderr but exit 0; null = absent/skip.

### FIX-03: curl|bash foot-gun in --cron template

The `cli/conjure update --cron` template previously emitted a `curl -fsSL .../install.sh | bash`
step. Replaced with `actions/checkout@11bd71901bbe5b1630ceea73d27597364c9af683 # v4.2.2`
pinned to a SHA, checking out conjure-src at `path: conjure-src`. Conjure is invoked as
`CONJURE_HOME=conjure-src conjure-src/cli/conjure` — no cp to /usr/local/bin (which breaks
CONJURE_HOME resolution at cli/conjure:24). AUTPR-02 existing tests still pass.

### FIX-04: hardcoded /tmp path in lib/inventory.sh DRY_RUN branch

Replaced `actual_output_path="/tmp/adopt-manifest-dryrun.json"` with the portable
`mktemp 2>/dev/null || mktemp -t conjure-adopt-dryrun.XXXXXX` fallback idiom. Also updated
the stale docstring comment that referenced the hardcoded path.

### FIX-05: exit 1 → exit 2 in dispatcher + cmd_publish + overlay scripts

Changed to conform with CLAUDE.md "exit 2, never exit 1" convention:
- `cli/conjure` unknown-command dispatcher: `exit 1` → `exit 2`
- `cmd_publish` unknown option: `return 1` → `return 2`
- `cmd_publish_skill` unknown option + missing skill name: `return 1` → `return 2`
- `scripts/init-overlay.sh` empty URL + clone failure: `exit 1` → `exit 2`; docstring updated
- `scripts/refresh-overlay.sh` no marker + backup failure + clone failure: `exit 1` → `exit 2`; D-04 stale comment removed; docstring updated

Preserved intentional exit-1 sites:
- `scripts/audit-setup.sh` line 297: `exit 1` for warnings — documented public API (0=pass, 1=warn, 2=error)
- `cli/conjure` cmd_update D-06 `return 1`: conflict-detection semantic, preserved with existing comment

### FIX-06: rm-rf regex hardening in pre-bash-block-destructive.mjs

Replaced the single `/rm\s+-rf\s+\/(?!\w)/` regex (which only matched `rm -rf /path`) with
`isDestructiveRm(cmd)` helper that: extracts all flag tokens after `rm`, checks for both
r-family (`-r`, `-R`, `--recursive`, combined `-rf`, `-fr`, etc.) and f-family (`-f`,
`--force`), then verifies the path starts with `/`, `~`, or `$`. Covers `rm -fr`, `rm -r -f`,
`rm -Rf` and all combined variants.
