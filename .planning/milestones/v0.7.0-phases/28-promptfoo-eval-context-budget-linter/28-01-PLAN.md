FUNCTION: _list_installed_skills <target_dir>

$PWD or $CONJURE_HOME.

FUNCTION: _yaml_escape_single <string>
Escape a string for single-quoted YAML scalar: replace every ' with '\''. Used for llm-rubric values and skill names in YAML.
